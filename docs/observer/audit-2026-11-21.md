## Methodology objections and research direction

1. **Source eligibility / executable mechanism mismatch:** preregistration asks for ≥12 “grounded” source cases while only 3/240 satisfy the later explicit uniqueness gate; historical SQL48 has **zero** such cases.
2. **Reused, unsuitable historical cohort:** [PR #125](https://github.com/kolihhan/semantic-text2sql-agent/pull/125) already found Count-unit coverage absent. Repeating a stricter Count mechanism on it adds almost no information about the key SQL branch.
3. **Automatic labels are not truth:** errors in source task intent make “grounded” insufficient for validated intervention. Only 1 relation candidate and no actionable relation SQL detector; ratio, filters, population not tested.
4. **No independent causal mismatch labels:** wrong strict SET EX does not establish counted-unit or relational failure. No model calls or candidate rewrites were performed, so **there is no measured strict SET/BAG EX uplift**.
5. **Source-disjoint claims limited:** 240-case selection excludes historical question IDs, but uses physical DBs among 49 previously exposed; only two TRAIN physical DBs remain protected. Do not mix TRAIN48/240, historical BIRD DEV100/DEV500 or HOLDOUT300.
